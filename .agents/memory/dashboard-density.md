---
name: Dashboard density
description: Keep dashboard controls compact so opportunities appear near the top.
---

The dashboard's introductory and control area should take minimal vertical space, with secondary controls and explanations accessible on demand.

**Why:** The user explicitly requested a compact redesign of the dashboard header, discovery, Gmail, summary, and explanatory area so it does not push jobs down.

**How to apply:** Prefer compact summaries and labeled disclosures over permanently expanded cards. Preserve access to all actions and keep current processing, failures, and reconnection needs apparent even when details are collapsed.
